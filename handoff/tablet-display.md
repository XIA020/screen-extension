# 屏幕扩展发布交接

- 分支为 `main`。最近验证环境为 Windows 11 x64、MatePad 和 GT6。根目录 README 提供安装、连接与构建步骤。
- 已验证两台设备在同一热点上分别使用独立副屏，单独断开 GT6 时 MatePad 串流继续。MatePad 已实测在活动串流中从复制切回扩展。GT6 使用 2200×1000 桌面、2780×1264 原生全屏串流，用户确认两侧黑边消失。
- 第二路启停保留已有屏幕位置。Windows 调整模式后先等待系统完成排列再校正。已用两台在线设备往返切换 1920×1080 和 2200×1000 验证位置。
- 后续重点是干净主机的双路安装、共用 MTT 适配器时的独立停用，以及两台设备同时在线时从复制恢复扩展。安卓直接点主机也需要单独验收。
- 两端运行配置和配对记录随设备本地保存。Android 正式签名密钥由发布者保管。调试、构建和安装包的生成规则见根目录 README。
